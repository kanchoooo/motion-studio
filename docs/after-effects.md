# 애프터이펙트(AE)로 가져가기 — 가능성 검토

질문: 모션스튜디오에서 만든 영상을 AE 파일로 저장해, AE에서 이어서 수정할 수 있을까?

## 결론

- **.aep 파일을 직접 만드는 것은 현실적으로 불가능하다.**
  - .aep는 공개되지 않은 바이너리 형식이다.
  - XML 판(.aepx)도 내부 대부분이 문서화되지 않은 데이터 덩어리라, 새로 만들어 내면 버전마다 깨진다.
- **대신 "AE 패키지"(소재 폴더 + 스크립트 한 개)로는 충분히 가능하다.**
  - AE에서 `파일 > 스크립트 > 스크립트 파일 실행`으로 `build.jsx`를 열면, 스크립트가 컴포지션·레이어·키프레임을 직접 만든다.
  - AE 공식 스크립트(ExtendScript)로 하는 방식이라 AE CC 2019 이후 버전에서 같은 결과가 나온다.
- 텍스트는 **살아 있는 텍스트 레이어**로, 위치·크기·회전·투명도 움직임은 **키프레임**으로 들어가서 AE에서 바로 고칠 수 있다.
- 일부 효과(그라데이션 마스크, 블렌드, 필터, 글자 하나하나 쪼갠 애니메이션 등)는 AE의 같은 기능으로 옮기기 어렵다. 이런 부분은 그 요소만 **투명 영상 레이어**로 넣는다(보이는 건 같고, 그 요소만 AE에서 다시 손봐야 함).

## 무엇이 어떻게 옮겨지나

| 모션스튜디오 | AE에서 | 비고 |
|---|---|---|
| 컴포지션 (크기·fps·길이) | 컴포지션 | 29.97fps 그대로 |
| 텍스트 요소 | 텍스트 레이어 (폰트·크기·자간·행간·색·정렬) | AE 컴퓨터에 같은 폰트가 있어야 함. 없으면 AE가 바꿔 보여 줌 |
| 이미지·로고·생성 이미지 | 푸티지 레이어 | 원본 파일을 패키지에 복사 |
| 영상 클립 | 푸티지 레이어 (시작·길이·속도) | |
| 사각형·원 같은 도형 (배경색·둥근 모서리·테두리) | 셰이프 레이어 | 단색·단순 그라데이션까지 |
| 그룹 (폰 목업 등) | 프리컴프 또는 부모(parent) 연결 | 안쪽 요소도 따로 수정 가능 |
| 움직임: 위치·크기·회전·투명도 | 키프레임 | 아래 "키프레임 만드는 법" |
| 이징 (power2.out 등) | 키프레임 속도·영향(ease) 근사 | 겉보기 같게 맞춤 |
| 배경음악·효과음·내레이션 | 오디오 레이어 (시작·길이·볼륨) | |
| 디자이너 직접 수정값 | 이미 반영된 상태로 들어감 | |
| SVG 캐릭터 연기, 마스크, 블렌드, 블러, 3D | 투명 영상 레이어 (ProRes 4444) | 그 요소만 AE에서 재작업 필요 |

## 키프레임 만드는 법 (두 가지)

1. **구워 넣기**: 앱이 매 프레임 각 요소의 위치·크기·회전·투명도를 읽어 키프레임으로 만든다.
   - 모양은 100% 같다.
   - 곡선을 단순화해서 키프레임 수를 줄인다(허용 오차 0.5px·0.5%). 그래도 키가 많아 AE에서 고치기는 다소 번거롭다.
2. **의미대로 옮기기**: 앱 런타임이 이미 GSAP 모션을 하나하나 기록하고 있다(시작·길이·이징·값, 편집 탭 모션 패널에서 쓰는 정보).
   - 이 정보로 "0.5초에 아래에서 올라오며 나타남(power2.out)"을 **키프레임 2개 + 이징**으로 옮긴다. AE에서 고치기 가장 좋다.
   - 옮길 수 없는 모션(CSS 변수, 경로, 글자 쪼개기 등)만 1번 방식으로 넘긴다.

→ **2번을 기본으로, 안 되는 것만 1번**으로 하는 게 좋다.

## 만들 범위와 일정 (제안)

| 단계 | 내용 | 예상 |
|---|---|---|
| 1. 시제품 | 내보내기 창에 "AE 패키지(실험)" 추가.<br>텍스트·이미지·영상·도형·오디오 레이어, 위치·크기·회전·투명도 키프레임(1·2번), 폰트 목록 안내 | 2~3일 |
| 2. 그룹·효과 | 그룹을 프리컴프/부모로 옮기기. 옮길 수 없는 요소는 그 요소만 투명 영상 레이어로 렌더 | 2일 |
| 3. 검수 | 와이프분 AE에서 실제 광고 2~3개로 확인하고 맞추기 | 1~2일 |

개발 맥에는 AE가 없다. 그래서 **실제 확인은 와이프분 컴퓨터의 AE**로 해야 한다.

## 확인이 필요한 것

- 쓰는 AE 버전(예: 2024, 2025)과 운영체제
- AE에서 주로 고치려는 것: 글자, 타이밍, 이징, 색 등. 가장 많이 고치는 것부터 정확하게 맞춘다.
- 회사 폰트를 AE 컴퓨터에도 설치했는지(같은 폰트가 있어야 텍스트가 똑같이 보인다)

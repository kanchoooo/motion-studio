## 중요한 발견과 설계 변경

### 1. GSAP와 디자이너 위치 수정의 충돌 → 겉 상자 방식으로 해결
- **문제**: 처음에는 CSS 개별 transform 속성(`translate`, `scale`)으로 위치·크기를 덮어쓰려 했다. 그런데 GSAP는 요소를 읽을 때 이 값을 자기 transform에 합친다(gsap.js 4908행). HyperFrames 렌더러는 타임라인을 다시 초기화하므로 값이 **두 번 적용**됐다.
- **해결**: 런타임이 편집 가능한 요소(`data-ms-id`)마다 보이지 않는 겉 상자(`data-ms-wrap-for`)를 씌우고, 디자이너의 위치·크기·회전은 겉 상자에만 적용한다. GSAP는 겉 상자를 건드리지 않으므로 충돌이 없다.
- **조건**: 편집 가능한 요소는 `position: absolute`여야 한다. Claude 규칙과 자동 검사로 강제한다. 흐름 배치 요소는 위치 편집을 비활성화하고 안내한다.
- **장점**: 드래그 편집 시 CSS 규칙만 바꾸면 되므로 미리보기를 즉시 갱신할 수 있다.

### 2. 텍스트 교체 시점
- Claude 스크립트가 글자를 쪼개 애니메이션(SplitText 등)하기 **전에** 텍스트를 바꿔야 한다.
- MutationObserver를 쓰면 HTML 파서가 각 `<script>`를 실행하기 직전에 반영된다(HTML 명세의 마이크로태스크 체크포인트). 검증 완료.

### 3. 영상 소재와 구간 속도
- HyperFrames의 `data-playback-rate`를 이용한다. 영상 소재가 빨라진 구간 안에 완전히 들어가 있으면 재생 속도도 같이 올린다.
- 구간 경계에 걸친 영상은 `data-ms-remap-partial`로 표시하고, 편집기에서 안내한다.
- 실제 영상 소재로 하는 검증은 Phase 2에서 진행한다.

### 4. 기타 운영 사항
- **GSAP CDN 의존**: HyperFrames 기본 템플릿은 jsDelivr CDN에서 GSAP을 불러온다. 회사망이나 오프라인을 고려해 프로젝트에 로컬 사본(`vendor/gsap.min.js`)을 넣는다.
- **없는 폰트**: 지정한 폰트가 없으면 기본 명조체로 대체된다. 폰트 스캔 결과와 대조해 "폰트 없음" 경고를 띄운다.
- **렌더 속도**: Intel 기준 15초 영상은 약 3~4분 걸린다. 편집 중에는 실시간 미리보기를 쓰고, 내보내기는 진행률을 표시한다. 빠른 확인용 "초안 품질" 옵션을 제공한다.
- **Claude 권한**: 계정 커넥터를 차단하려면 `strictMcpConfig: true`와 `settings.disableClaudeAiConnectors: true`가 필요하다. 읽기 권한도 프로젝트 폴더 안으로 제한한다(`canUseTool`).

# 포함된 HyperFrames 스킬

출처: heygen-com/hyperframes (Apache-2.0), `hyperframes skills` 0.8.151 기준.
모션스튜디오의 Claude는 터미널을 쓰지 않으므로 작성 규칙 위주의 스킬만 포함한다.

| 스킬 | 용도 |
|---|---|
| hyperframes-core | 컴포지션 구조, data-* 타이밍 속성, 결정적 렌더 규칙 |
| hyperframes-animation | 모션 규칙, 장면 설계도, 장면 전환, GSAP |
| hyperframes-creative | 색, 타이포, 구성, 페이싱 등 크리에이티브 방향 |
| hyperframes-keyframes | 키프레임 설계 |
| motion-graphics | 짧은 광고형 모션그래픽 (키네틱 타이포, 로고 스팅 등) |

갱신 방법: `HOME=<임시폴더> npx hyperframes skills` 로 받은 뒤 위 5개만 복사한다.
